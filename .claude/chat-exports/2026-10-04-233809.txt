| MCP | What it's for |
|---|---|
| **GitHub** | PRs, issues, code search, and Actions runs. Yours needs fixing. |

  you get fewer outdated API suggestions. This is probably the highest-value one
  for learning frontend. |
| **Figma** | Reads designs and turns them into components. It's listed as
  needing auth for you. |

  built-in tools. |

  against your DB. |
| **MongoDB / Redis** | Official MCPs for NoSQL and cache inspection. |
| **Docker** | Manage containers and compose stacks. |
| **Sentry** | Pull real production errors and stack traces while debugging. |
| **Vercel / Netlify / Cloudflare** | Deploys, logs, and env vars. |
| **Stripe** | Test payment flows and inspect customers and webhooks. |
| **Memory (knowledge graph)** | Persistent notes across sessions. |

  problems. |
