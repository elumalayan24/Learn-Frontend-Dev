  using design tokens. I haven't opened it in a browser, so it's untested.

- **Tokens:** The colors are CSS variables in a `<style>` block, with light
  values in `:root` and dark overrides in `.dark`. They cover surface, card,
  text, muted, border, brand, inverse, footer, success, danger and warning. The
  values are RGB channels, so opacity modifiers like `text-on-brand/80` work.
- **Tailwind mapping:** `tailwind.config` maps the variables to utilities such
  as `bg-brand`, `text-muted`, `border-line` and `bg-success-bg`. It also adds
  `rounded-control`, `rounded-card` and `rounded-hero`, `shadow-card` and
  `shadow-card-hover`, and a font stack.
- **Markup:** The page now uses these semantic classes instead of hard-coded
  `indigo-600`, `slate-800` and similar. Most of the per-element `dark:`
  variants are gone, because the tokens switch themselves when `.dark` is set.
- **Rebranding:** To change the look, edit the `--color-brand-*` values (and the
  dark ones) in the `<style>` block. For example, swap the indigo triplets for
  teal and the whole page follows.
