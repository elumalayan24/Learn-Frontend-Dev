- **Claude Code:** put the MCP servers in `~/.claude.json`, or add each one with
  `claude mcp add --scope user`.

Neither `psql` nor `uvx` is on your PATH on this machine, so the `postgres-mcp`
  server won't run yet. You need two things:

1. **PostgreSQL itself.** Install it from postgresql.org, or run `winget install
  PostgreSQL.PostgreSQL`. The installer asks you to set the password for the
  `postgres` user, so enter `admin`. It uses port 5432 by default, which matches
  the string. If you already have PostgreSQL installed, `psql` just isn't on
  your PATH. Add its `bin` folder, usually `C:\Program

  install uv`, then restart your terminal or IDE.

When both are installed, run `psql -U postgres -h localhost -c "select 1"` and
  enter `admin` when prompted. If it prints a result, the credentials work.

`admin` is a weak password and it's stored in plain text in this file. That's
  fine for a local learning database. Don't reuse it anywhere that's reachable
  from outside your machine.
